# Contributing

Contributions are welcome!

## Reporting Issues

If you find a bug, have a feature request, or notice something that could be improved, please open a GitHub Issue.

Before opening a new issue, please check existing issues to avoid duplicates.

## Pull Requests

To contribute code or documentation:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and run the checks listed in the README.
4. Review the staged diff for private data, then commit with a clear message.
5. Open a Pull Request.

Please keep Pull Requests focused on a single change or purpose when possible.

## Questions

If you have questions about the project, feel free to open a GitHub Issue.

Thank you for contributing!
